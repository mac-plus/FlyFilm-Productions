# FlyFilm Productions

Fast, responsive one-page website for a film production company focused on clear value, quick navigation, and high-conversion contact paths.

## Files

- `index.html` - site structure and content
- `styles.css` - responsive layout and visual system
- `script.js` - project switching, active navigation, and quick-brief interactions

## Preview locally

```bash
python3 -m http.server 4173
```

Then open `http://127.0.0.1:4173`.

## Customize before launch

Replace these placeholders in `index.html` and `script.js`:

- `hello@flyfilmproductions.com`
- `+1 (555) 010-1444`
- `https://cal.com`

Update the featured work copy, service list, and response-time claims to match your real business.
